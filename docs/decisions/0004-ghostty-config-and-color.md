# Ghostty configuration and CLI color

The owner asked Knotch to use the same settings as Ghostty and supplied a screenshot of monochrome Claude Code. Read-only inspection found that the installed Knotch process inherited `NO_COLOR=1`, `TERM=dumb`, and empty `COLORTERM` from its coding-tool launch environment. Ghostty sets TERM and COLORTERM for its child, but inherited NO_COLOR survived and told applications to suppress color. The prior forced Menlo/palette configuration was a separate appearance mismatch.

Knotch now clears inherited NO_COLOR before engine initialization. Explicit Ghostty `env` configuration or subsequent shell startup files can still set it. This changes neither system environment nor the user's configuration files. Existing processes retain their environment; the owner must restart Knotch and its terminal session to pick up this fix.

The runtime follows the pinned upstream macOS app's `ghostty_config_load_default_files` and `ghostty_config_load_recursive_files` sequence, without interpreting Knotch's command-line arguments as Ghostty configuration. Removed the forced Menlo, colors, padding, keybinding reset, memory limits, and per-surface font-size override. Native Command-C/V now use the engine's configured keybinding lookup. App-owned shortcuts and unsupported native actions remain limitations. Read-only comparison with installed Ghostty resolved JetBrainsMono Nerd Font, 14 pt, Catppuccin Mocha, 8-point padding, and opacity 0.97. The native engine probe independently checks font size, foreground/background and opacity; it does not claim pixel-identical window transparency.

Themes are bundled from the same pinned upstream build dependency, with its MIT notice. No separate Ghostty installation is required. Configuration edits currently require restart; no automatic reload was added. Knotch's black native chrome, clipboard adapter and unsupported tabs/splits remain app-specific.

Test builds isolate harness/overlay fixtures from personal configuration so configured commands and bindings cannot contaminate PTY tests. A separate test-only config probe loads personal configuration but creates no terminal or child process and reports only selected appearance values. Native PTY checks assert NO_COLOR is absent and COLORTERM/TERM are truecolor/xterm-ghostty. The harness exercises engine-configured Command-C, native paste, resize, and 60 seconds of retained hidden output. These tests do not establish Claude's post-restart appearance or send any model request.
