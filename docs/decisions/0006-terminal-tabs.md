# Terminal tabs inside the expanded notch

The owner requested multiple tabs and a way to identify work across them. A horizontal, scrollable strip below the camera-safe header preserves terminal width and keeps all tabs inside the expanded notch. Each tab is a separate real Ghostty surface, PTY and shell owned by SessionStore. Selection is a stable UUID; view attachment and focus change without freeing or recreating another surface. Hidden sessions continue to drain output. Closing a background tab retains the current selection; closing the selected tab chooses a neighbor. Quitting closes every session only after the live-session confirmation.

Ghostty's pinned internal API supplies SET_TITLE and SET_TAB_TITLE actions. Knotch copies bounded title data, strips controls/bidirectional formatting, and treats it as plain display text. A manual rename takes precedence until cleared. The original directory is the fallback label and the default directory for a new tab. Cmd-T/the plus button creates a shell; folder-plus opens a project; Cmd-1 through Cmd-9 select existing tabs. Per-tab close and rename actions carry UUIDs so delayed callbacks cannot target whichever session happens to be selected later. Queued engine new-tab actions require the originating tab still to be selected.

Tracking here means identifying sessions and returning to their retained terminal output. A live shell is labeled running; an observed shell exit is labeled ended. Titles are not interpreted as trustworthy agent task status. No screen scraping, transcript persistence, inferred task completion, manual Done workflow or agent hooks are included. Custom names, tab order and sessions are in-memory for this app run; workspace restoration remains later work.

The native fixture uses three clean shells to check distinct surface/PID/PTY identities, real OSC titles, sanitation, rename precedence, selected input routing, scrollback retention, actual delayed output in inactive tabs, and independent/neighbor/last-session close behavior. Existing single-panel motion, focus, camera alignment and minimise tests remain in the suite. Physical pointer, global shortcuts, performance/soak, VoiceOver and multi-display qualification remain separate open items.
