# Native toolbox in the retained notch workspace

On September 26 the owner requested a broader toolbox using Omninotch's public feature inventory as a reference. Knotch now adds a fixed **Tools** tab beside Clipboard and Settings, while retaining the real Ghostty terminal engine and existing Clipboard flows. This is an implementation expansion, not a claim of complete Omninotch parity. The [feature map](../omninotch-feature-map.md) separates implemented behavior from tested outcomes and remaining dependencies.

## Interface and ownership

The searchable native SwiftUI catalog contains 19 tools grouped into Focus, Everyday, and Utilities. Stars save favourites in app preferences; selecting a tool opens its detail view inside the existing panel. All Tools and a back action return to the catalog. Terminal, Tools, Clipboard, and Settings keep the same saved panel dimensions, camera-safe header, and reveal/minimise rules.

Tools stores survive panel hiding and utility-tab changes. Selecting Tools detaches the visible Ghostty view without destroying its surface or process; returning reattaches the same terminal. Native picker presentation uses the existing dialog-level coordinator, with balanced nested holds. Attached native sheets also lower the overlay and hold presentation until dismissal. Tool services own cancellation and teardown; application termination calls their shutdown paths.

## Feature boundaries

- Quick Notes, local To-dos, timer settings/deadline, completed focus count, and teleprompter text/appearance save to app preferences. Focus presets are 25/5/15 minutes, with a 1–180 minute custom timer. A saved deadline reconciles elapsed time; no notifications or automatic Pomodoro cycle are implemented. Teleprompter scrolling pauses when hidden or when leaving its tool.
- File Shelf copies selected or dropped files/directories into its own local Application Support storage. Its index and directory are owner-only. Retention is 1/7/30 days or forever. Imports are bounded to 20 selections, 2,000 entries, 512 MiB aggregate, and depth 24; links and aliases are rejected. Inspection/copy/export run off the main actor, with progress and overlapping-operation rejection. Remove/expiry deletes shelf copies, not originals. Quick Look, open/reveal, export, drag-out, and native AirDrop actions are implemented. This differs from Clipboard, which retains file references.
- Calendar reads a selected day's events and the next seven days through EventKit. Reminders reads lists and supports adding/completing items. Full-access requests happen only after an explicit Connect action; neither tool silently requests access on navigation.
- Mirror starts AVFoundation capture only after **Start Camera**. It previews with optional mirroring, does not record/upload, and stops on hide or tool departure. It reports denied/restricted/no-camera states.
- Now Playing connects explicitly to an already-running Music or Spotify app using public AppleScript. It reads track details and supports play/pause, previous/next, and seeking. This is not a system-wide Now Playing API. Apple Events automation permission may be required; polling runs only while the tool is visible.
- Ask Knotch uses the Apple Foundation Models model when Apple Intelligence is available. Conversation/session state is in memory, generation can be stopped, and context-limit/unavailable-model errors are shown. The model receives no tools and cannot read app data or execute terminal commands.
- AI Usage performs a bounded read of `account/rateLimits/read` through the installed authenticated `codex app-server --stdio` after Refresh. It displays returned windows/reset dates and stops its child process afterward. It does not inspect credential files, launch a model request, or purchase usage. Claude Code and GitHub Copilot are labelled manual snapshots with observation times; no live provider integration is claimed.
- Weather searches cities and fetches current conditions plus seven days from Open-Meteo, with cached successful data. It does not request location access. Convert supports local unit calculations and an explicit dated Frankfurter currency-rate request. Stocks uses Alpha Vantage `GLOBAL_QUOTE`, requires an owner-supplied Keychain key, limits the watchlist to five symbols, and labels standard-access quotes end-of-day. A refresh uses one request per ticker; automatic missing/stale refresh is throttled to 15 minutes.
- Emoji is a searchable curated copy palette. Shortcuts invokes `/usr/bin/shortcuts` with argument arrays to list and explicitly run the owner's existing shortcuts; jobs have bounded output, timeouts, cancellation, and shutdown handling.
- System Stats samples CPU, approximate used memory, and network throughput through public system APIs while visible. Keep Awake uses a timed `NoIdleSleep` power assertion, released on expiry/disable/shutdown. Sound reads and writes the default output device's exposed CoreAudio volume/mute properties and can opt into volume-change notifications with a separate notch HUD. Unsupported devices show availability limits; the HUD does not suppress the system HUD.

No third-party dependency was added. The Ghostty pin, Apple Silicon deployment target macOS 26, and qualified Xcode 27 / Swift 6.4 toolchain remain unchanged. New functionality uses Apple frameworks and explicit network/provider or installed-command boundaries.

## Evidence and limits

`scripts/test-models.sh`, `scripts/test-tools.sh`, and the Release build passed. The tool suite covers notes/to-dos reload, timer deadline reconciliation and pause/reset, teleprompter offset state, local conversions, and File Shelf copy/reload/expiry/rollback boundaries with an asynchronous responsiveness/export check. Its process fixture runs disposable `/bin/sleep` jobs to verify timeout/cancellation; it does not execute an owner Shortcut.

The native suites passed [21 Settings/workspace checks](../test-results/toolbox-settings.json), [49 overlay checks](../test-results/toolbox-overlay.json), and [47 Clipboard checks](../test-results/toolbox-clipboard.json), 117 total. New workspace checks cover the 19-tool catalog, shared panel dimensions, retained real Ghostty shell/surface through utility navigation, nested dialog balance, attached native sheet levels, and hiding without requesting camera access. The older bounded overlay and Clipboard regression scopes remain unchanged.

A real store probe fetched London search results and a seven-day Open-Meteo forecast, plus a dated Frankfurter rate. A read-only installed Codex app-server probe and the installed Refresh control returned account quota windows. Native UI inspection showed actual system-stat readings, a timer still counting after minimise/reopen and reset afterward, and a manual Claude usage editor sheet above the workspace which was canceled. The native File Shelf picker also presented unobscured and returned after Cancel.

Actual camera capture, real EventKit access/data, Music/Spotify automation/playback, stock key/quotes, AirDrop delivery, real Shortcut execution, audio changes, power assertions, and volume-HUD delivery were not run. Installed Ask Knotch generated “Hello!” in response to a harmless greeting prompt; the test conversation was cleared. This is a generation smoke test, not an accuracy or error-path qualification. These require separate qualification; a visible UI or a successful build does not establish their behavior. Physical cross-app hover, global hotkey delivery, multi-display changes, VoiceOver, and performance/soak limits from the terminal alpha also remain open. Final installation/restart evidence is recorded separately after the final build; this decision does not assert a new installed executable hash.
