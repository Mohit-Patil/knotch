# Omninotch reference and Knotch feature map

Reference: the public [Omninotch website](https://omninotch.app/) reviewed September 26, 2026. Its advertised feature categories guide this inventory; marketing descriptions are not evidence that every feature works or that Knotch implements equivalent behavior. Knotch's source and actual qualification define the results below. No complete parity claim is made.

**Implemented** means a native code path exists. **Tested** describes only exercised behavior. **Not run** means the integration or effect still needs qualification. Provider access and macOS permissions can prevent otherwise implemented features from being usable.

| Reference category | Knotch implementation | Actual evidence / remaining scope |
| --- | --- | --- |
| Notch toolbox | Tools tab with 19 searchable native tools, saved favourites, three categories and detail navigation; shared saved panel size. | 21 native Settings/workspace checks passed, including catalog, utility navigation, same Ghostty surface/PID, nested dialogs, attached sheets and visibility suspension. Full keyboard/VoiceOver and physical cross-app hover remain unqualified. |
| Now Playing | Explicit Music/Spotify connection, track/artwork display, play/pause, previous/next and seek using public AppleScript. | Compiled; real automation permission, track reads and playback **not run**. No system-wide Now Playing integration. |
| On-device chat | Apple Foundation Models conversation, streaming, stop/new conversation, unavailable-model and context-limit handling; memory-only history with no tools. | Installed UI generated “Hello!” from a harmless greeting prompt; streaming completion and clearing the conversation were observed. Broader generation/error cases not run. Depends on eligible Mac/region, enabled Apple Intelligence and ready model. |
| AI usage | Read-only Codex account quota windows/reset times on Refresh via installed authenticated app-server. Claude Code/Copilot manual observations with timestamps. | Real Codex read probe and installed Refresh UI passed. Manual Claude editor presented above the panel and canceled. Claude/Copilot live account integration is **not implemented**; saving/reloading manual UI entries is unqualified. |
| Teleprompter | Editable local script, size/speed controls and scrolling; pauses when hidden or leaving the tool. | Offset/play/pause/reset store tests passed. Actual long-script reading, perceived scrolling and physical controls **not run**. |
| Files / AirDrop | Separate File Shelf copies, directory import, configurable expiry, Quick Look, open/reveal, export, drag-out and native AirDrop action. | Copy/reload/removal/expiry, duplicate names, nested folders, corrupt-index protection, link rejection and asynchronous import/export tests passed. Original preservation verified. Native Add Files picker presented unobscured and Cancel returned to the shelf. Physical file drop/Quick Look/AirDrop delivery **not run**. |
| Mirror | Explicit AVFoundation camera start, mirrored preview, stop and denied/restricted/no-device states; stops on hide. | Native hidden-tools fixture confirms no permission request on navigation/hide. Actual permission grant and camera capture **not run**. |
| Weather | City search, current conditions and seven-day Open-Meteo forecast with cached data; no location permission. | Real store probe fetched London search and seven forecast days. Broader locations, provider failure/cached-data UI and prolonged refresh **not run**. |
| Stocks | Five-symbol watchlist and Alpha Vantage end-of-day quotes; owner key in Keychain, cache and refresh limits. | Compiled; actual key storage, provider response/quotas and quotes **not run**. Live prices are **not implemented**. |
| Timers / Pomodoro | 25-minute focus, 5/15-minute break presets and custom timer; saved deadline, pause/reset and focus count. | Deadline/reload, simulated completion once, pause/reset tests passed. Native UI timer continued while minimized and was reset. Notifications and automatic cycle switching are **not implemented**; real sleep/relaunch timing **not run**. |
| Calendar | EventKit day view and next-seven-days events, explicit full-access connection. | Compiled; real permission/data and calendar refresh **not run**. No event creation/editing. |
| Reminders | EventKit lists, completion and add-to-list, explicit full-access connection. | Compiled; real permission/data/write **not run**. |
| To-dos | Local tasks, completion/delete, saved independently from Apple Reminders. | Add/trim/completion/reload store tests passed. Native UI lifecycle **not run**. |
| System stats | Visible-only public API CPU, approximate used memory and network throughput. | Actual readings visually present in native UI. Accuracy calibration, prolonged sampling and performance measurement **not run**. |
| Shortcuts | Lists existing macOS Shortcuts and explicitly runs a selected name via argument arrays; stop/timeouts/bounded output. | Process timeout/cancellation fixture passed using disposable sleep jobs. Actual owner Shortcut execution **not run**. |
| Emoji | Searchable curated palette copying an emoji to pasteboard. | Compiled; full copy/search UI flow **not run**. Not the entire system emoji catalog. |
| Converter | Length, weight, temperature, volume, area and speed; explicit dated Frankfurter currency rate. | Local numeric conversions and same-currency behavior passed; real Frankfurter store probe passed. Full UI and failure handling **not run**. |
| Quick notes | Multiple local notes, automatic save, edit/delete. | Note save/reload store tests passed. Full UI editing **not run**. |
| Keep Awake | Timed NoIdleSleep assertion, expiry/disable/shutdown release. | Compiled; actual assertion creation/expiry/sleep behavior **not run**. Does not promise to defeat lid-close or forced sleep. |
| Volume HUD / Sound | Default-output volume/mute where CoreAudio exposes controls; opt-in listener and notch HUD. | Compiled; actual volume/mute writes, hardware events, listener delivery and HUD **not run**. Does not replace/suppress macOS HUD. |
| Clipboard | Existing local mixed history, copy/pin/search/filter, carousel, terminal shelf, private image-path insertion and drag flows. | 47 native regression checks passed; prior installed carousel/shelf-to-terminal physical drags remain documented. Floating-screenshot-thumbnail delivery and full VoiceOver **not run**. |

Knotch additionally retains independent real Ghostty PTYs, terminal tabs/titles/scrollback, project/home-shell launch, and local Ghostty configuration. Existing terminal qualification does not establish full AI-agent compatibility: prior Codex/Claude terminal checks covered launch/trust-prompt cancellation, not authenticated requests or paid actions.
